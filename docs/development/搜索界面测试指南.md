# 搜索界面测试指南

## 📋 测试概述

本文档提供搜索界面的完整测试指南，包括功能测试、样式测试、性能测试和边界测试。

## 🧪 测试环境准备

### 1. 确保后端服务运行

```bash
# 启动后端服务（在项目根目录）
./start_server.sh
```

### 2. 配置微信开发者工具

- 打开微信开发者工具
- 加载项目：`miniprogram/` 目录
- 设置 → 项目设置 → 本地设置 → 勾选"不校验合法域名"
- 确认 `services/api.js` 中的 IP 地址正确

### 3. 准备测试数据

确保后端数据库中有测试数据，包括：
- 不同情绪标签的漂流瓶内容
- 包含常见搜索关键词的内容

## 🎯 测试优先级

### P0（必须通过）
- 测试 1-8：所有基础功能测试
- 测试 15-18：边界和错误处理
- 测试 12：搜索响应时间

### P1（重要）
- 测试 9-11：样式测试
- 测试 13-14：性能测试
- 测试 21-23：兼容性测试

### P2（可选）
- 测试 19-20：特殊场景测试

## 📝 测试注意事项

1. **真机测试优先**：模拟器可能无法完全还原真机效果，务必在真机上测试
2. **多设备测试**：至少在 iOS 和 Android 各一台设备上测试
3. **记录问题**：发现问题时记录详细的复现步骤和截图
4. **性能监控**：使用微信开发者工具的性能面板监控性能指标
5. **网络环境**：测试不同网络环境下的表现
