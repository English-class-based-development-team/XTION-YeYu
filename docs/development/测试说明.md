# 测试说明

## 测试文件位置

所有测试文件位于 `miniprogram/tests/` 目录下：
- `testAnonymousId.js` - 匿名ID生成工具测试
- `testEmotionSimilarity.js` - 情绪相似度计算工具测试
- `testValidator.js` - 数据验证工具测试
- `testErrorHandler.js` - 错误处理工具测试
- `runAllTests.js` - 测试运行器（统一执行所有测试）

测试工具位于 `miniprogram/utils/testUtils.js`

## 运行测试的方法

### 方法1：使用测试页面（推荐）

1. 在 `app.json` 的 `pages` 数组中添加 `"pages/test/index"`（已创建测试页面）
2. 在微信开发者工具中编译项目
3. 通过页面路径跳转到测试页面，或直接在地址栏输入：`pages/test/index`
4. 点击"运行所有测试"按钮
5. 查看页面上的测试结果，同时控制台会输出详细的测试日志

### 方法2：在控制台直接运行

在微信开发者工具的控制台中执行：

```javascript
const runAllTests = require('./miniprogram/tests/runAllTests.js');
runAllTests.runAllTestSuites();
```

### 方法3：运行单个测试套件

```javascript
// 测试匿名ID生成
const testAnonymousId = require('./miniprogram/tests/testAnonymousId.js');
testAnonymousId.runAllTests();

// 测试情绪相似度计算
const testEmotionSimilarity = require('./miniprogram/tests/testEmotionSimilarity.js');
testEmotionSimilarity.runAllTests();

// 测试数据验证
const testValidator = require('./miniprogram/tests/testValidator.js');
testValidator.runAllTests();

// 测试错误处理
const testErrorHandler = require('./miniprogram/tests/testErrorHandler.js');
testErrorHandler.runAllTests();
```

## 测试内容

### 1. 匿名ID生成测试
- ✅ 唯一性：同一设备生成相同ID
- ✅ 一致性：持久化后保持一致
- ✅ 格式验证：16位16进制字符串
- ✅ 用户名生成：格式为"用户XXXX"
- ✅ 不可逆性：ID不包含可识别信息

### 2. 情绪相似度计算测试
- ✅ 完全相同情况：相似度为1
- ✅ 完全相反情况：相似度接近0
- ✅ 边界值测试：0,0 和 10,10
- ✅ 正常值测试：中等相似度在合理范围
- ✅ 超出范围测试：返回0
- ✅ 批量计算测试：正确排序
- ✅ 性能测试：100条数据 < 2000ms（实际约50-100ms）

### 3. 数据验证工具测试
- ✅ 正常值验证：通过
- ✅ 边界值验证：0和10通过
- ✅ 超出范围验证：失败
- ✅ 类型错误验证：失败
- ✅ 空值验证：失败
- ✅ 内容长度验证：正常、空、超长、边界（300字）

### 4. 错误处理工具测试
- ✅ Error对象格式化
- ✅ 字符串错误格式化
- ✅ 网络错误识别
- ✅ API结果检查：成功、失败、null/undefined

## 测试结果解读

测试报告包含以下信息：
- **总测试数**: 运行的测试用例总数
- **通过**: 通过的测试用例数
- **失败**: 失败的测试用例数
- **成功率**: 通过率百分比

每个测试用例会输出：
- ✅ 通过：绿色标记
- ❌ 失败：红色标记，并显示错误信息

## 注意事项

1. 测试环境需要在微信开发者工具中运行（因为使用了wx API）
2. 某些测试会修改本地存储，建议在测试前后重置存储
3. 性能测试的时间可能因设备性能而异，但应该远低于2秒要求
4. 测试结果会在控制台详细输出，建议打开控制台查看
