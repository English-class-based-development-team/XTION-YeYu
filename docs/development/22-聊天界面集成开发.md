### 2. 组件属性和事件

**属性（Properties）**：

```javascript
properties: {
  messages: {
    type: Array,
    value: []
  }
}
```

消息数据结构：
```javascript
{
  role: 'user' | 'ai',
  content: 'message text'
}
```

**事件（Events）**：

- `bindsend`：发送消息事件
  - 参数：`{ message: string }`
  - 触发时机：用户点击发送按钮或按下 Enter 键

### 3. 集成到主页面

**主页面数据结构**：

```javascript
data: {
  chatMessages: [
    {
      role: 'ai',
      content: 'Hi! I\'m your personal psychology agent. How can I help you today?'
    }
  ]
}
```

**主页面事件处理**：

```javascript
onChatSend(e) {
  const { message } = e.detail;
  
  // 添加用户消息
  const newMessages = [...this.data.chatMessages, {
    role: 'user',
    content: message
  }];

  this.setData({
    chatMessages: newMessages
  });

  // 打开 FullscreenChat（可选）
  this.setData({
    showFullscreenChat: true
  });

  // 模拟 AI 回复（1.5s 延迟）
  setTimeout(() => {
    const aiMessage = {
      role: 'ai',
      content: 'I understand. Let me help you with that. How are you feeling about this situation?'
    };
    
    this.setData({
      chatMessages: [...this.data.chatMessages, aiMessage]
    });
  }, 1500);
}
```

**WXML 集成**：

```xml
<!-- 底部 ChatInterface -->
<view class="chat-container">
  <chat-interface 
    messages="{{chatMessages}}"
    bindsend="onChatSend"
  ></chat-interface>
</view>
```

### 4. 交互流程

1. 用户在 ChatInterface 输入框输入消息
2. 用户点击发送按钮或按下 Enter 键
3. 组件触发 `bindsend` 事件，传递消息内容
4. 主页面接收事件，添加用户消息到消息列表
5. （可选）主页面打开 FullscreenChat 模态框
6. 主页面模拟 AI 回复（1.5s 延迟）
7. 消息列表更新，ChatInterface 显示最新的 2 条消息
