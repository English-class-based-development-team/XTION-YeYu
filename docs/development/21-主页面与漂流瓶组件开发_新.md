**UI 设计（严格按照 DriftBottle.tsx 设计）**：

- 尺寸：`576rpx × 768rpx`（`w-72 h-96`）

#### 3.2 底部波纹效果

- 位置：`position: absolute; bottom: 64rpx;`

- 使用双层波纹（不同颜色渐变）
- 动画：`scaleX` 和 `opacity` 循环变化，时长 3.5s

#### 3.3 瓶子结构

1. **瓶塞**：
   - 尺寸：`112rpx × 56rpx`（`w-14 h-7`）
   - 渐变：`linear-gradient(to bottom, #8B5A3C, #6B4A2C)`
   - 圆角：`border-radius: 32rpx 32rpx 0 0`

2. **瓶颈**：
   - 尺寸：`88rpx × 128rpx`（`w-11 h-16`）
   - 渐变：`linear-gradient(to bottom, rgba(232, 155, 109, 0.7), rgba(243, 184, 154, 0.8))`

3. **瓶身**：
   - 尺寸：`288rpx × 320rpx`（`w-36 h-40`）
   - 圆角：`64rpx`
   - 渐变：`linear-gradient(to bottom right, rgba(232, 155, 109, 0.85), rgba(243, 184, 154, 0.75), rgba(248, 230, 208, 0.7))`

4. **瓶底**：
   - 尺寸：`288rpx × 80rpx`
   - 渐变：`linear-gradient(to bottom, rgba(232, 155, 109, 0.8), rgba(216, 138, 93, 0.7))`
   - 圆角：`border-radius: 0 0 64rpx 64rpx`

#### 3.4 玻璃效果

- **流光效果**：
  - 使用 `@keyframes flow-light`
  - opacity 循环：`0.4 → 0.7 → 0.4`
  - 时长：3s

- **左上高光**：
  - 白色渐变：`linear-gradient(to bottom right, rgba(255, 255, 255, 0.7), transparent)`
  - 模糊：`filter: blur(40rpx)`

- **底部光晕**：
  - 白色半透明：`rgba(255, 255, 255, 0.4)`
  - 模糊：`filter: blur(32rpx)`

#### 3.5 瓶内信纸

- 尺寸：`192rpx × 224rpx`（`w-24 h-28`）
- 背景：`linear-gradient(to bottom right, #fff5eb, #ffe8d5)`
- 圆角：`28rpx`
- 旋转动画：`rotate(-4deg) → rotate(-2deg) → rotate(-4deg)`，时长 5s
- **Plus 图标容器**：
  - 尺寸：`96rpx × 96rpx`（`w-12 h-12`）
  - 背景：`rgba(232, 155, 109, 0.2)`
  - 圆角：`999rpx`
  - 图标：`+`，颜色 `#E89B6D`
- **装饰线条**：3 条水平线，不同宽度和透明度

#### 3.6 漂浮动画

- 瓶子主体：
  - y 轴：`0 → -24rpx → 0`
  - 旋转：`-1.5deg → 1.5deg → -1.5deg`
  - 时长：5s，循环

- 信纸：
  - 独立旋转动画，时长 5s

#### 3.7 浮光粒子（3个）

- 位置：分布在瓶子周围不同位置
- 动画：
  - y 轴向上移动（-160rpx ~ -200rpx）
  - opacity：`0.7 → 0` 或 `0.6 → 0`
  - scale 变化
  - 不同的时长（4s, 5s, 4.5s）和延迟
- 渐变颜色：`linear-gradient(to bottom right, #F8E6D0, #E89B6D)`

#### 3.8 瓶子阴影

- 柔和阴影效果：`rgba(232, 155, 109, 0.2)`
- 模糊：`filter: blur(16rpx)`
