## 🔌 API 集成

### 新增 API 方法

**文件**：`miniprogram/services/api.js`

```javascript
/**
 * 搜索漂流瓶内容
 * @param {String} query - 搜索关键词
 * @param {Number} limit - 返回数量限制（默认 20）
 * @param {Number} offset - 偏移量（默认 0）
 * @returns {Promise} Promise 对象，返回 {posts: [], total: number}
 */
function searchPosts(query, limit = 20, offset = 0) {
  const queryString = buildQueryString({ q: query, limit, offset });
  return request(`/search?${queryString}`, {
    method: 'GET'
  });
}
```

**接口说明**：
- 请求方法：`GET`
- 请求路径：`/search?q={query}&limit={limit}&offset={offset}`
- 返回格式：`{ posts: [{id, emotion_tag, content, created_at, anonymous_id}], total: number }`

### 数据处理

**时间格式化**：
- `formatTimeAgo()` 方法将 ISO 时间字符串转换为相对时间
- 规则：
  - < 1分钟：显示"刚刚"
  - < 60分钟：显示"X分钟前"
  - < 24小时：显示"X小时前"
  - < 7天：显示"X天前"
  - ≥ 7天：显示"M月D日"

**数据映射**：
```javascript
const results = response.posts.map(post => ({
  id: post.id || post._id,
  tag: post.emotion_tag || post.tag || '未知情绪',
  content: post.content || '',
  timeAgo: this.formatTimeAgo(post.created_at),
  anonymousId: post.anonymous_id || ''
}));
```

## 🔄 交互流程

### 搜索流程

1. **打开搜索**：
   - 用户点击主页右上角搜索按钮
   - 触发 `onSearchClick()`
   - 设置 `showSearchModal = true`
   - SearchModal 组件显示，播放入场动画

2. **输入搜索词**：
   - 用户在输入框中输入搜索关键词
   - 或点击示例标签（"孤独"、"焦虑"、"需要陪伴"、"寻找平静"）
   - 实时更新 `query` 状态

3. **执行搜索**：
   - 用户点击"搜索共鸣"按钮或键盘搜索键
   - 触发 `onSearch(e)` 方法
   - 显示 loading 提示："搜索中..."
   - 调用 `api.searchPosts()` 获取搜索结果
   - 处理返回数据，转换时间格式
   - 关闭 SearchModal，显示 SearchResultsWall

4. **查看结果**：
   - SearchResultsWall 显示搜索结果
   - 结果以双列瀑布流布局展示
   - 显示找到的结果数量
   - 点击卡片可查看详情（调用 ResonanceDetail 组件）

5. **返回主页**：
   - 点击返回按钮或 ResonanceDetail 关闭
   - 触发 `onSearchResultsClose()`
   - 清空搜索状态，返回主页

### 状态管理

**主页状态**（`pages/index/index.js`）：

```javascript
data: {
  showSearchModal: false,      // 是否显示搜索模态框
  showSearchResults: false,    // 是否显示搜索结果墙
  searchQuery: '',             // 当前搜索关键词
  searchResults: []            // 搜索结果数据
}
```

**关键方法**：
- `onSearchClick()`：打开搜索模态框
- `onSearchModalClose()`：关闭搜索模态框
- `onSearch(e)`：执行搜索并显示结果
- `onSearchResultsClose()`：关闭搜索结果
- `formatTimeAgo(dateString)`：格式化时间为相对时间

## ⚡ 性能优化

### 动画性能
- ✅ 使用 `transform` 和 `opacity` 属性（GPU 加速）
- ✅ 避免使用 `margin`、`width`、`height` 等触发重排的属性
- ✅ 合理的动画时长（300-400ms）

### 渲染性能
- ✅ 使用 `wx:if` 条件渲染，避免不必要的组件渲染
- ✅ 列表渲染使用 `wx:key` 指定唯一标识
- ✅ 卡片动画错开延迟，避免同时触发大量动画

### 网络优化
- ✅ 搜索时显示 loading 状态
- ✅ 完整的错误处理和用户提示
- ✅ 支持分页加载（limit, offset 参数）

## 🐛 错误处理

### 网络错误
```javascript
try {
  const response = await api.searchPosts(query.trim(), 20, 0);
  // 处理成功
} catch (error) {
  wx.hideLoading();
  console.error('搜索失败:', error);
  wx.showToast({
    title: error.message || '搜索失败，请稍后重试',
    icon: 'none',
    duration: 2000
  });
}
```

### 边界情况处理
- ✅ 空搜索关键词：禁用搜索按钮
- ✅ 无搜索结果：显示"找到 0 个相关共鸣"
- ✅ 时间格式化失败：显示"未知时间"
- ✅ API 调用失败：显示友好错误提示
