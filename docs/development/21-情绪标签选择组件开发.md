# 2.1 情绪标签选择组件开发

## 📋 功能概述

实现情绪标签选择组件，基于 `CreateMessageCard` 设计，用户可以通过点击标签进行编辑，输入的情绪标签会自动映射到对应的情绪值（价度和唤醒度）。

## 🎯 开发目标

1. 实现情绪标签气泡 UI（渐变背景、圆角、阴影、白色文字）
2. 实现标签点击编辑功能（可编辑文本，最大长度10字符）
3. 实现标签到情绪值的映射逻辑
4. 优化输入性能（防抖优化）
5. 确保 UI 设计与 Yeyu_ui_design 完全一致

## 🔧 技术实现

### 1. 创建情绪标签映射工具函数

**文件路径**：`miniprogram/utils/emotionTagMapper.js`

**功能**：
- 将用户输入的情绪标签文本映射到价度（valence）和唤醒度（arousal）值
- 支持预设标签映射（如"兴奋"、"开心"、"平静"等）
- 支持自定义标签的情绪值推断（基于关键词分析）

**关键实现**：
- 预设映射表：定义了常见情绪标签到情绪值的映射关系
- 关键词推断：使用文本分析的方法，根据标签中的关键词推断情绪值
  - 正面情绪关键词：开心、快乐、高兴等 → 价度值偏高（6-9）
  - 负面情绪关键词：难过、悲伤、沮丧等 → 价度值偏低（1-4）
  - 高唤醒度关键词：兴奋、焦虑、紧张等 → 唤醒度值偏高（7-9）
  - 低唤醒度关键词：平静、放松、沮丧等 → 唤醒度值偏低（1-3）

**代码示例**：
```javascript
// 映射标签到情绪值
const { valence, arousal } = emotionTagMapper.mapTagToEmotion('开心');
// 结果：valence: 8, arousal: 8

// 验证情绪值范围
const isValid = emotionTagMapper.validateEmotionValues(valence, arousal);
```

### 2. 实现情绪标签气泡 UI 组件

**文件路径**：
- `miniprogram/pages/publish/index.wxml`
- `miniprogram/pages/publish/index.wxss`
- `miniprogram/pages/publish/index.js`

**UI 设计（严格按照 CreateMessageCard 设计）**：
- **渐变背景**：`linear-gradient(to right, #ff9966, #ff8855)`
- **圆角**：`border-radius: 36rpx`（对应 `rounded-[18px]`）
- **阴影**：`box-shadow: 0 10px 15px -3px rgba(0, 0, 0, 0.1), 0 4px 6px -2px rgba(0, 0, 0, 0.05)`（对应 `shadow-lg`）
- **文字样式**：白色文字 `color: #ffffff`，字体大小 `28rpx`（对应 `text-sm`），字体粗细 `font-weight: 600`（对应 `font-semibold`）
- **内边距**：`padding: 20rpx 40rpx`（对应 `py-2.5 px-5`）
- **间距**：`margin-bottom: 24rpx`（对应 `mb-3`）

**交互功能**：
- 点击标签进入编辑模式
- 输入框自动聚焦并选中文本
- 限制最大长度为10字符
- 失焦或按下回车退出编辑模式
- 防抖优化输入事件（300ms延迟）

**代码结构**：
```javascript
// 数据结构
data: {
  tag: '我的心情',        // 标签文本
  isEditingTag: false,   // 是否正在编辑
  valence: 5,            // 价度值
  arousal: 5,           // 唤醒度值
  tagInputDebounceTimer: null, // 防抖定时器
}

// 主要方法
onTagClick()           // 点击标签进入编辑模式
onTagInput(e)          // 标签输入事件（带防抖）
onTagBlur()            // 标签失焦退出编辑模式
onTagConfirm(e)        // 标签输入完成（按下回车）
updateEmotionValues()  // 根据标签文本更新情绪值
```

### 3. 性能优化

**防抖优化**：
- 标签输入事件使用防抖处理（300ms延迟）
- 立即更新显示的文本（保证用户体验）
- 延迟更新情绪值（减少计算频率）

**setData 优化**：
- 合并多次更新为一次 setData
- 只更新需要渲染的数据字段
