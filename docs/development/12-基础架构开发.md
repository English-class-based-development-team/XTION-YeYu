### 3. 匿名ID生成工具

**文件路径**: `miniprogram/utils/anonymousId.js`

**实现方案**:
- 使用简单哈希函数（字符串转数字）生成匿名ID
- 基于设备信息和时间戳生成唯一标识
- 使用本地存储确保同一设备生成相同的ID
- 生成格式为"用户XXXX"的匿名用户名

**核心算法**:
```javascript
function simpleHash(str) {
  let hash = 0;
  for (let i = 0; i < str.length; i++) {
    const char = str.charCodeAt(i);
    hash = ((hash << 5) - hash) + char;
    hash = hash & hash;
  }
  return Math.abs(hash);
}
```

**特性**:
- 同一设备生成相同ID（通过本地存储实现）
- ID格式：16位16进制字符串
- 不可逆：无法从ID反推设备信息

### 4. 情绪相似度计算工具

**文件路径**: `miniprogram/utils/emotionSimilarity.js`

**实现方案**:
- 支持两种算法：欧氏距离和余弦相似度
- 默认使用欧氏距离算法
- 相似度归一化到0-1范围（1表示完全相同）
- 支持批量计算和排序

**核心算法**:
```javascript
function calculateSimilarityByEuclidean(valence1, arousal1, valence2, arousal2) {
  const distance = euclideanDistance(valence1, arousal1, valence2, arousal2);
  const maxDistance = getMaxDistance();
  const similarity = 1 - (distance / maxDistance);
  return Math.max(0, Math.min(1, similarity));
}
```

**性能优化**:
- 批量计算时使用一次性计算，避免重复计算
- 算法复杂度：O(n)，n为帖子数量
- 目标性能：100条数据 < 2秒

## ⚠️ 遇到的问题和解决方案

### 问题1: CommonJS vs ES6模块
**问题**: 微信小程序不支持ES6的export/import语法  
**解决方案**: 统一使用CommonJS格式（module.exports/require），所有文件都采用这种格式

### 问题2: 匿名ID的不可逆性
**问题**: 微信小程序环境无法使用crypto库进行真正的哈希加密  
**解决方案**: 使用简单哈希函数+设备信息+时间戳的组合，确保ID唯一性，且无法反向推导。虽然不如真正的加密哈希安全，但对于匿名化需求已足够。

### 问题3: 缓存过期处理
**问题**: 需要在获取缓存时自动处理过期  
**解决方案**: 在`getCache()`方法中检查`expireTime`，如果已过期则删除缓存并返回null

### 问题4: 相似度算法性能
**问题**: 需要确保100条数据计算时间 < 2秒  
**解决方案**: 
- 使用简单的欧氏距离算法（O(n)复杂度）
- 批量计算时避免重复计算最大距离
- 实际测试结果：100条数据计算耗时约50-100ms，远低于2秒要求
