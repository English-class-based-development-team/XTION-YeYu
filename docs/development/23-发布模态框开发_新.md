# 2.3 CreateMessageCard 模态框开发

## 📋 功能概述

实现 CreateMessageCard 模态框，作为用户发布情绪内容的主要入口。用户点击 DriftBottle 后打开此模态框，可以编辑情绪标签和文本内容，然后发送到共鸣流。

## 🎯 开发目标

1. 实现 CreateMessageCard 模态框（参考 `Yeyu_ui_design/components/CreateMessageCard.tsx`）
2. 实现情绪标签气泡（可编辑）
3. 实现内容卡片（可编辑）
4. 实现提交按钮和验证逻辑
5. 集成情绪标签映射工具
6. 确保 UI 设计与 Yeyu_ui_design 完全一致

### 2. 组件属性和事件

**属性（Properties）**：

```javascript
properties: {
  show: {
    type: Boolean,
    value: false
  }
}
```

**数据（Data）**：

```javascript
data: {
  // 情绪标签
  tag: '我的心情',
  isEditingTag: false,
  
  // 情绪值
  valence: 5,
  arousal: 5,
  
  // 文本内容
  content: '',
  contentPlaceholder: '点击编辑你想分享的内容...',
  isEditingContent: false,
  contentLength: 0,
  
  // 提交状态
  canSubmit: false,
  isSubmitting: false,

  // 动画
  animationClass: ''
}
```

**事件（Events）**：

- `bindclose`：关闭模态框事件
  - 触发时机：用户点击背景或关闭按钮

- `bindsend`：发送消息事件
  - 参数：`{ tag: string, valence: number, arousal: number, content: string }`
  - 触发时机：用户点击发送按钮且验证通过

### 3. 验证逻辑

**提交按钮禁用条件**：

按照 CreateMessageCard 的逻辑：
```javascript
disabled={!tag.trim() || !content.trim() || content === "点击编辑你想分享的内容..."}
```

**验证函数**：

```javascript
validateCanSubmit() {
  const { tag, content, contentPlaceholder } = this.data;
  
  const canSubmit = (
    tag.trim().length > 0 &&
    content.trim().length > 0 &&
    content !== contentPlaceholder
  );
  
  this.setData({
    canSubmit
  });
}
```

**提交流程**：

1. 防止重复提交（检查 `isSubmitting`）
2. 验证是否可以提交（检查 `canSubmit`）
3. 收集数据（tag, content, valence, arousal）
4. 验证数据（使用 `validator.validateContent()` 和 `validator.validateTag()`）
5. 设置提交状态（`isSubmitting: true`）
6. 触发发送事件
7. 重置表单
8. 重置提交状态（`isSubmitting: false`）

### 4. 情绪标签映射

**工具函数**：`utils/emotionTagMapper.js`

**映射逻辑**：

当用户输入或修改标签时，自动计算情绪值：

```javascript
onTagInput(e) {
  const tag = e.detail.value;
  
  // 更新情绪值
  const { valence, arousal } = emotionTagMapper.mapTagToEmotion(tag);
  
  this.setData({
    tag,
    valence,
    arousal
  });
  
  this.validateCanSubmit();
}
```

**常见标签映射**：
- "我的心情"：价度 5，唤醒度 5（中性）
- "开心"：价度 8，唤醒度 6
- "难过"：价度 2，唤醒度 4
- "焦虑"：价度 3，唤醒度 8
- "平静"：价度 6，唤醒度 2
- 自定义标签：使用关键词匹配或默认为中性

  console.log('Create message send:', { tag, content, valence, arousal });

  // 保存用户情绪数据
  this.setData({
    userEmotion: {
      tag,
      valence,
      arousal,

  // TODO: 调用 publishPost API
